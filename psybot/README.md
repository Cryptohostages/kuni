# Запись к школьному психологу · ЛИТ 1533

Telegram-бот, через который ученики лицея записываются к школьному психологу и задают ему вопросы анонимно. Психолог в том же боте видит записи, открывает и закрывает время, отвечает на вопросы и выгружает журнал консультаций.

## Что умеет

**Ученик**

- выбирает день и свободное время, указывает тему встречи (можно не указывать) и, если хочет, пишет пару слов психологу;
- видит свои записи и может отменить запись, тогда время снова становится свободным;
- получает напоминания: за день и за час до встречи;
- задаёт вопрос анонимно: психолог видит только текст, ответ приходит в тот же чат;
- в разделе «Нужна помощь» находит телефоны, по которым ответят сразу.

**Психолог** (команда `/admin` или кнопка «Кабинет психолога» в меню)

- **Записи** на сегодня, завтра и неделю, карточка каждой записи со ссылкой на ученика;
- отмена записи с причиной: ученик сразу получает сообщение, а это время закрывается для записи;
- после встречи отметка «состоялась» или «неявка»;
- **Окошки**: недельный обзор и редактор дня, где время открывается и закрывается одним нажатием; можно закрыть весь день (например, на больничный) или открыть время вне сетки, например в субботу; пересекающиеся окошки бот открыть не даст;
- **Вопросы**: ответ уходит автору, при этом психолог не знает, кто он; автору, который присылает спам, можно запретить писать анонимно, не узнавая, кто это;
- **Журнал**: статистика за месяц и выгрузка в CSV, открывается в Excel;
- утренняя сводка: кто сегодня придёт;
- уведомления о новых записях, отменах и вопросах.

## Запуск

### 1. Создать бота

1. Написать [@BotFather](https://t.me/BotFather) команду `/newbot`, придумать имя и username.
2. Скопировать токен вида `1234567890:AA...`.
3. Там же: `/setjoingroups` → выбрать бота → **Disable**. Бот рассчитан только на личные сообщения, в группах он молчит.
4. Узнать Telegram ID психолога: пусть психолог напишет [@userinfobot](https://t.me/userinfobot), бот ответит числом.
5. Психолог должен один раз нажать «Старт» в нашем боте, иначе бот не сможет присылать ему уведомления.

### 2. Настроить

```bash
cp .env.example .env
```

В `.env` обязательно заполнить `BOT_TOKEN` и `ADMIN_IDS`. Имя психолога и кабинет тоже стоит указать: они показываются ученикам. Остальные настройки расписаны в самом `.env.example`.

### 3а. Запустить через Docker (удобнее всего на сервере)

```bash
docker compose up -d --build
docker compose logs -f   # посмотреть, что бот запустился
```

База лежит в папке `data/` рядом с проектом и переживает перезапуски.

### 3б. Запустить без Docker

Нужен Python 3.11 или новее.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m bot
```

### Аватарка

В `assets/` лежит аватарка бота. Поставить её можно одной командой (при остановленном или запущенном боте):

```bash
python -m bot set-avatar
```

или вручную через @BotFather → `/setuserpic` → файл `assets/avatar.png`.

Описание бота и список команд бот выставляет сам при запуске.

## Расписание

По умолчанию психолог принимает по будням с 9:00 до 17:00, встреча 45 минут, перерыв 15, то есть окошки в 9:00, 10:00 и так до 16:00. Сетка меняется в `.env`: `WORK_DAYS`, `DAY_START`, `DAY_END`, `SLOT_MINUTES`, `BREAK_MINUTES`. После перезапуска бот сам уберёт свободные окошки старой сетки и откроет новые; уже сделанные записи останутся.

- `AUTO_OPEN=true`: рабочие дни сами открываются для записи на 4 недели вперёд, психолог закрывает то, когда занят (уроки, совещания, каникулы).
- `AUTO_OPEN=false`: всё закрыто, психолог сам открывает нужное время.

Ученики видят расписание на `BOOKING_DAYS_AHEAD` дней вперёд (по умолчанию 14), психолог на 4 недели.

## Конфиденциальность

- Всё хранится в одном файле `data/bot.sqlite3` на том компьютере, где запущен бот. Файл доступен только пользователю, от имени которого запущен бот. Копию для надёжности стоит хранить так же аккуратно.
- Имя, класс, тема и комментарий к записи видны только психологу (и тем, кто указан в `ADMIN_IDS`).
- У анонимного вопроса психолог видит только текст и день, без точного времени. Кто задал вопрос, бот помнит, только пока ждёт ответа: через сутки после ответа эта связь стирается из базы. В логи автор не попадает.
- Под ответом психолога бот предупреждает, что запись на встречу уже не анонимная.
- Тексты «О психологе», «Это конфиденциально» и «Нужна помощь» лежат в `bot/texts.py`. Их стоит показать психологу и поправить под него.

## Как устроен проект

```
bot/
  __main__.py        запуск
  app.py             сборка бота и диспетчера
  config.py          настройки из .env
  db.py              база SQLite: окошки, записи, вопросы
  texts.py           тексты, которые удобно править
  screens.py         экраны ученика (текст + кнопки)
  admin_screens.py   экраны психолога
  scheduler.py       новые окошки, напоминания, утренняя сводка
  handlers/          обработка кнопок и сообщений
    admin/           кабинет психолога
tests/               тесты: от проверки класса «8б» до целых сценариев записи
```

Бот написан на [aiogram 3](https://docs.aiogram.dev/). Любой экран — это функция, которая возвращает текст и кнопки, поэтому навигация не плодит сообщения: по нажатию кнопки бот переписывает текущее.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты прогоняют бота целиком без Telegram: подменяют сетевую часть и нажимают кнопки за ученика и психолога.
